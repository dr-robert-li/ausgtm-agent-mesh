| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06-01 | Information disclosure | the long-lived refresh token / client secret leaking | mitigate | GOOGLE_WORKSPACE_OAUTH resolved only inside execute() (04-03); the blob never returned in results nor logged; doc instructs storing it as a secret env var, not in code |
| T-04-06-02 | EoP | gmail_send / sheets_append executing without approval | mitigate | both are write-class -> approval_required (manifest); reached only after runner._resume_after_approval is_approved() (unchanged); reads (drive_search) are ungated by design (read category) |

| T-04-06-SC | Tampering | google client libs install (supply chain) | mitigate | blocking-human package-legitimacy checkpoint before install ([ASSUMED] until verified) |
