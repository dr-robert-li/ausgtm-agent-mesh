## Pattern Assignments

### `tools/gateway.py` (service / engine) — EXTEND, DO NOT REPLACE

**Analog:** itself — the existing `ToolSpec` / `load_tool_pack` / `ToolGateway` shape (D-03 says *carry what it drops*).

**`ToolSpec` to extend** (`tools/gateway.py:21-37`): frozen dataclass. ADD `integration_style: str`,
`input_schema_ref: str | None`, `output_schema_ref: str | None` (all present in the manifest, silently
dropped today). Keep the existing write-class invariant in `validate()` unchanged.
```python
@dataclass(frozen=True)
class ToolSpec:
    name: str
    provider: str
    category: ToolCategory
    description: str
    approval_required: bool
    credential_secret_name: str | None
    resource_bindings: dict[str, Any]
    def validate(self) -> None:  # KEEP: write-class ⇒ approval_required invariant
        if self.category in WRITE_CATEGORIES and not self.approval_required:
            raise ValueError(...)
```

**`load_tool_pack` to extend** (`tools/gateway.py:40-55`): the loop already reads `raw[...]`; add the
three dropped keys — `raw.get("integration_style", "direct_api")`, `raw.get("input_schema_ref")`,
`raw.get("output_schema_ref")`.

**`execute()` signature change** (`tools/gateway.py:74-86`): today `execute(self, name, parameters)` returns
an echo stub. RESEARCH (Pitfall 2) requires it carry correlation — change to take the `ToolCall` (or a small
context) so the D-10 span, the resolver, and the failed-`tool_call` row all have `task_id`/`tenant_id`. The
current stub return shape is the **fallback** every adapter degrades to when creds are absent (D-11) — keep
that exact dict shape (`{"tool", "provider", "category", "stub": True, ...}`) as the no-creds return.

**Imports pattern to follow** (this file, `tools/gateway.py:10-18`): `from __future__ import annotations`,
stdlib, then `import yaml`, then `from agent_mesh.contracts.enums import ...`. New heavy provider SDKs are
**lazy in-function imports** (see degradation pattern below), never module-level.

### `worker/runner.py` (executor) — THE read-seam (audit item A), mirror the write loop UNGATED

**Analog:** the write-gating loop in `process()` (`worker/runner.py:74-113`) + `_execute` (`166-173`).

**Write loop to mirror** (`runner.py:74-113`) — builds a gated `ToolCall(AWAITING_APPROVAL)`, opens an
approval, parks the task. The **read seam does the inverse**: iterate `result.proposed_reads`, build
`ToolCall(category=ToolCategory.READ, approval_required=False)`, call `self._execute(call)` **immediately,
ungated, no approval ledger**, persist via `upsert_tool_call` (tenant-scoped), append a string summary to
`evidence`. Reads run **before** the write-gate branch.
```python
# EXISTING write path (the thing to mirror, NOT to gate reads through):
for proposed in result.proposed_writes:
    call = ToolCall(task_id=task_id, tenant_id=task.tenant_id,
        tool_name=proposed["tool_name"], category=ToolCategory(proposed["category"]),
        approval_required=True, status=ToolCallStatus.AWAITING_APPROVAL,
        parameters=proposed.get("parameters", {}), requester_id=task.requester.requester_id)
    self._repo.upsert_tool_call(call)
    # ... approvals.build_approval_request / open_approval / park ...
```

**`_execute` + stub fallback to reuse unchanged** (`runner.py:166-173`):
```python
def _execute(self, call: ToolCall) -> dict:
    if self._gateway is None:
        return {"stub": True, "note": "no tool gateway configured; write not executed",
                "tool": call.tool_name}
    return self._gateway.execute(call.tool_name, call.parameters)  # update to pass `call` (Pitfall 2)
```
The `gateway is None → stub` line is the read seam's default-lane safety: with no gateway injected, reads
still record a deterministic stub row and the green suite holds.

> **Planner flag (RESEARCH "real-graph wrinkle"):** on the real `_run_langgraph` path, `proposed_writes` are
> pulled from `final_state["__interrupt__"][0].value`; reads are accumulated channel state, NOT in the
> interrupt payload. Confirm `compiled.invoke` returns `proposed_reads` alongside `__interrupt__`, or surface
> reads in both branches / execute reads before the gate. The stub/default lane has no interrupt, so the
> green-suite story holds regardless.

### `observability.py` (tool-event span, D-10) — copy `_approval_span`

**Analog:** `_approval_span` in `services/approvals.py:159-193` — the closest concrete analog (NOT bare
`get_tracer()`). It is a `@contextmanager` that no-ops when the tracer is None, builds `trace_metadata()`,
calls `set_span_metadata(span, meta)`, and is telemetry-only (nothing branches on span data). The tool-event
span (D-10) copies this exact shape, adding tool-specific attributes.
```python
@contextmanager
def _approval_span(name, *, tenant_id, task_id, requester_id, approval_state):
    tracer = obs.get_tracer()
    if tracer is None:
        yield None
        return
    meta = obs.trace_metadata(tenant_id=tenant_id, client_slug=..., task_id=task_id,
        session_id=None, requester_id=requester_id, entrypoint="approval",
        approval_state=approval_state)
    with tracer.start_as_current_span(name) as span:
        obs.set_span_metadata(span, meta)
        yield span
```
Second analog: `_task_root_span` (`orchestrator.py:213-233`). The tool span adds attributes
`tool`/`provider`/`category`/`integration_style`/`approval_state`/`outcome` (RESEARCH "Tool-event OTel span"
example). **NEVER set raw creds or full payloads as attributes** (`set_span_metadata` already filters to known
keys — `observability.py:221-233`).

## Shared Patterns

### Degradation / stub-fallback (CLAUDE.md §8, D-11) — applies to ALL new tool code

**Source:** `observability.py:56-77` (module-level `*_available()` guards) + `orchestrator.py:113-125, 171-191`
(lazy in-function imports of optional deps).
```python
def langfuse_available() -> bool:
    try:
        import langfuse  # noqa: F401
        return True
    except Exception:
        return False
# heavy/optional deps are imported INSIDE the function that needs them, never at module top:
#   from langgraph.checkpoint.postgres import PostgresSaver   # orchestrator.py:115
```
**Apply to:** every adapter, the credential resolver, the schema validator, the aggregate-schema fetch.
Provider SDKs (`hubspot`, `googleapiclient`, `composio`) are lazy-imported; creds-absent → return the
gateway stub dict (`gateway.py:79-86`). Keeps `make test`/`make smoke` importable + creds-free.

### Approval gate (SEC-01/02) — UNCHANGED for writes; reads NEVER touch it

**Source:** `services/approvals.py` — `payload_hash` (`:42-46`), `build_approval_request` (`:49-60`),
`is_approved` (`:253-263`, APPROVED + payload re-hash), and the write-execution path in `runner.py:135-154`.
**Apply to:** `hubspot_create_deal` + every GWS write/send stays gated through this exact path (no weakening).
The read seam (item A) MUST NOT route through `is_approved()` (RESEARCH anti-pattern).

### Tenant scoping (DUR-02)

**Source:** `repository.list_tool_calls(task_id, tenant_id)` (`repository.py:41, 132-136, 760+`) and
`_pending_calls` (`runner.py:161-164`). **Apply to:** every new `tool_calls` read (reads + schema-reject rows)
stays tenant-scoped.

### Opt-in live lane (D-11) — per-provider, NOT the shared `live_creds` fixture

**Source:** `tests/test_cascade_live.py` — `pytestmark = pytest.mark.live` (`:49`), inline
`pytest.skip(...)` on the provider's OWN env presence (`_anthropic_creds_present()`, `:60-61, :97-98`),
inline live-resource build, real-call assertion. `make test` runs `-m "not live"` (`Makefile:31-32`);
`make test-live` runs `-m live` (`Makefile:34-35`); marker declared in `pyproject.toml:73-74`.

> **Planner flag:** the conftest `live_creds` fixture (`tests/conftest.py:115-127`) gates on MODEL creds
> (`ANTHROPIC_API_KEY`/`VERTEX_PROJECT_ID`/`CF_AIG_WRAPPER_URL`) — do NOT reuse it for HubSpot/GWS/Composio/Nango.
> Copy the *shape*: each live test module is `@pytest.mark.live` and skips on its OWN env var
> (`HUBSPOT_PRIVATE_APP_TOKEN`, `GOOGLE_WORKSPACE_OAUTH`, `COMPOSIO_API_KEY`, `NANGO_*`).
