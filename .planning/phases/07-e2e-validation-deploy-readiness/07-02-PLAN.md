DESIGN CORRECTION (PATTERNS, empirically confirmed): `app.py` exposes only /healthz,
/v1/tasks, /slack/events, /v1/approvals. THERE IS NO /mcp HTTP ROUTE. `mcp_server.build_mcp_server`
is FastMCP (mcp_server.py:60, `# pragma: no cover - needs mcp extra`). So D-03's "TestClient ingress"
does NOT apply to MCP. Use the in-process MCP entry instead.

Default-lane MCP entry (analog tests/smoke.py:42-46):
  request_from_mcp(tenant_id="t", client_slug="c", mcp_subject="svc", text="<prompt>") -> svc.create_task(...)
Use a WRITE-trigger prompt verb (e.g. "create a new HubSpot deal for ACME Corp") so the graph pauses at
the write_gate interrupt — that pause IS the long-running checkpointed job that the restart resumes.

DURABILITY mechanism (analog tests/test_checkpointer_resume.py:45-83, copy VERBATIM):
  - gate: `_backend_available("langgraph.checkpoint.sqlite")` (lines 30-37); skip cleanly if absent.
  - require the `agents_stack` fixture (conftest.py:90-103 — langgraph + deepagents importable).
  - db_path = str(tmp_path / "checkpoints.sqlite")   # FILE-backed, NEVER :memory:
  - config = {"configurable": {"thread_id": "tenant-t::task-<id>"}}   # DUR-02: thread_id == tenant-scoped task_id
  - conn = sqlite3.connect(db_path, check_same_thread=False); saver = SqliteSaver(conn)
  - graph = build_graph().compile(checkpointer=saver); paused = graph.invoke({"prompt": _PROMPT}, config)
  - assert "__interrupt__" in paused and paused["__interrupt__"][0].value["proposed_writes"]
  - del graph; del saver; conn.close()                # simulated process death
  - conn2 = sqlite3.connect(db_path, check_same_thread=False); saver2 = SqliteSaver(conn2)
  - resumed = build_graph().compile(checkpointer=saver2).invoke(Command(resume=True), config)
  - assert "__interrupt__" not in resumed and resumed.get("decision") is True and resumed.get("review")

ARTIFACT (drive-surface runner.py:115-119): the run's reviewer summary / OrchestrationResult +
any `result_summary` persisted on the task. Assert a NON-EMPTY artifact (the `review` survives the
restart-resume in the checkpoint).

GATING (PATTERNS SP-2 row 2): E2E-02 default lane carries NO `live` marker — it is the sqlite fallback
in `make test`, gated only on backend importability + `agents_stack`. The Postgres lane is
TEST_DATABASE_URL-gated via orchestrator._select_checkpointer()/close_checkpointer()
(analog test_checkpointer_resume.py:86-125; conftest.pg_dsn:74-87).

NOTE: the `_service` rebind (SP-1) does NOT apply here — E2E-02's resume is graph-level, never HTTP.
