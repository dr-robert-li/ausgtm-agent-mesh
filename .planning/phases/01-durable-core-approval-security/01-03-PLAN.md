Output: token issue/verify in approvals.py, fail-closed enforcement at both ingress points, the new APPROVAL_SIGNING_SECRET setting, and the SEC-01/SEC-02 test suite.

| MCP client → submit_approval tool | Second ingress into the SAME approval ledger; must be gated identically |
| approval decision → record_decision (ledger mutation) | The write-gate; only a verified token may advance it |
