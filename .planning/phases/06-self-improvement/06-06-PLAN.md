<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| promotion → running config | A promotion must NOT change live behavior until an explicit human-owned reload |
| rollback → active pointer | Rollback must actually restore the previous version, not just mark a flag |
| mutated artifact → approval | A patch edited after approval must not promote |
