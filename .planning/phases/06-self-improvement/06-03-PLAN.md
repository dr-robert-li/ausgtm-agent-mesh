<objective>
Add the GEPA-style log-driven reflective proposer (SI-03) as a SEPARATED OFFLINE
meta-agent: it mines durable, tenant-scoped execution traces (Postgres `tool_calls` +
task records — NOT live Langfuse spans), reflects to diagnose failures, and emits INERT
`SelfImprovementProposal` diffs through the existing `reflect_on_task` seam (status=DRAFT,
nothing executes). It runs a bounded loop that caps optimization iterations and
re-validates on the held-out set each round — with the held-out pool protected from the
proposer's visibility.

This plan OWNS the SI-01a held-out isolation invariant (the zero-overlap test) because the
proposer is the actor constrained not to see the held-out set.

Purpose: SI-03 (offline inert proposer + bounded loop) + SI-01a (held-out distinct from
optimization signal). Hard invariants: Option C inertness, no runtime mutation, bounded
roster (the proposer is NOT a new live supervisor agent — D-07, CLAUDE.md §8).
Output: `reflective_proposer.py` + default-lane inertness/isolation/loop-cap tests.
</objective>
